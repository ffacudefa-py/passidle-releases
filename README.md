# PASSIDLE — descargas

RPG idle que convierte tus pasos reales en un equipo de personajes coleccionables.

**Bajá la última versión para Android:** [Releases › Latest](https://github.com/ffacudefa-py/passidle-releases/releases/latest) → `passidle-<versión>.apk`.
Instalala encima de la que tenés: no perdés tu progreso.

**iPhone / navegador:** https://passidle---rpg-idle-con-inter.web.app

Este repositorio tiene sólo las APK publicadas. La app avisa sola cuando hay una versión nueva.
